# 部署字体

后端镜像安装可再分发的 AR PL 宋体和文泉驿字体，所有中文 PDF 使用嵌入字体，不再退回依赖阅读器字体包的 CID 字体。

周报、月报继续使用已确认示例的仿宋版式。请将有相应使用授权的 `FangSong_GB2312.ttf` 放在本目录，或设置 `PIPESIGHT_FONT_DIR` 指向服务器上的字体目录。Compose 将目录只读挂载到 `/app/fonts`，并设置 `PDF_DIGEST_FONT_PATH=/app/fonts/FangSong_GB2312.ttf`。没有该字体时，启动预检会明确失败，不静默改变简报字体。

字体二进制不随仓库分发，也不进入后端镜像构建上下文。可用 `PDF_CJK_FONT_PATH` 指定其他可嵌入的 TrueType 正文字体；`PDF_DIGEST_FONT_PATH` 用于简报正文。

启动预检会实际解析字体，验证常用中文、英文、数字及中英文标点，空文件或仅含拉丁字母的字体不能通过。显式指定的字体若缺失、损坏、不支持嵌入或缺少本次内容所需字形，导出会明确报错；即使进程之前已经注册过其他字体，也不会静默回退。未显式配置的本地开发环境继续按原有系统字体顺序选择。PDF 不使用未嵌入的 CID 字体兜底。
