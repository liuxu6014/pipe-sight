# 报告读取与操作边界

报告详情、版本列表、历史版本正文和导出记录采用一致的读取规则：所有者可读取自己的报告，当前认证用户为管理员时可只读核对其他用户的报告。管理员范围由接口从认证身份计算，不接受客户端传入的权限开关。

跨用户只读查看时，详情返回 `readOnly: true`。页面禁用编辑、保存、恢复、配图操作及导出文件操作，保留正文预览、引用、历史版本预览和导出记录查看。

报告修改、历史恢复、创建导出及下载文件仍校验所有者；此次修复不改变这些写入和下载权限，不更改数据库记录或报告正文。

回归覆盖：`test_pipeline_controller.py` 校验四类读取接口只从认证身份派生管理员范围；`test_research_simplified_20261025.py` 校验跨用户默认拒绝、管理员只读范围及写操作仍被拒绝；`editor-autosave.test.js` 校验只读查看不会自动保存或创建版本。
