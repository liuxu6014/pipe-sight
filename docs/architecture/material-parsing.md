# 上传资料与解析状态

- 文件先写入受控上传目录，再保存到 `knowledge_files`；资料篮只保存来源关联。
- `FILE_SCAN_MODE`、`FILE_SCAN_COMMAND`、`FILE_SCAN_TIMEOUT_SECONDS` 在环境文件加载后读取。修改配置后，API 与 Worker 都需重启。
- 默认 `external`：执行已配置的外部扫描命令；未配置或扫描未通过时保持不可用，不得绕过扫描进入解析。
- 本地开发环境已显式配置 `basic`：执行基础文件检查与可执行文件伪装检测，不等同于带病毒库的专业扫描。生产应使用 `external` 并配置真实扫描器。
- Worker 执行扫描与正文提取，状态由 `queued` → `parsing` → `ready` / `failed` 更新；失败时保存原因，用户可点“重试”重新排队。
- 资料篮在有待解析文件时每 3 秒刷新资料状态；完成后停止轮询。页面退出清理定时器，账号切换丢弃旧响应。资料库与报告选材页也自动更新状态。
- 上传文件在资料篮返回的来源类型为 `file`，报告选材必须按内部资料读取，不能先当作新闻查询。
- 只有解析完成且正文非空的本人资料才能通过报告生成后端的选材校验。页面“已解析，可用于生成”不表示报告已经生成。
- 资料详情页的“编辑资料”仅向接口明确返回 `canManage: true` 的用户显示，名称和正文直接在当前页原位编辑，顶部提供保存、取消，不弹出编辑框。保存通过原有 PUT 接口提交 `expectedVersion`，发生版本冲突或请求失败时保留编辑区输入，不覆盖他人的新版本。
- 修订正文保存在 `edited_text`，后续检索、摘要提取和新生成任务使用修订内容；原始文件、提取正文和已有报告快照不改写。下载仍为原始上传文件，不是修订正文的重新打包文件。
