# 报告任务状态展示

- 任务进度使用 `generation_tasks` 的持久化状态和起止时间；页面不再把空阶段列表默认成“资料校验进行中”。
- 目前真实记录的生命周期为任务提交、后台执行、结果保存。未记录的解析、检索、质量检查、配图等细分过程不伪造为已执行阶段；配图与导出仍由各自资源状态管理。
- `completed` 显示任务完成，已保存结果对应完成状态；失败和取消显示终止状态，后续结果阶段为未执行，不继续等待。
- 执行记录仅展示真实提交、开始、结束时间和结果说明，不使用“正在读取任务状态”代替终态日志。
- 生成方式来自冻结模型配置；历史任务未记录方式时明确显示未记录，不把完成任务标为等待结果。
- 当前报告正文与本次任务结果不同时，仅提示两者不同，不推断发生时间，也不覆盖已有报告修改。
- 目标字数使用实际提交的大纲；没有提交大纲的旧任务才回退到模板快照。
- “使用模板”展示冻结快照中的实际模板名称，不展示模板编号或版本；历史任务未记录名称时明确显示“模板名称未记录”。
- 重试只针对失败或取消任务，创建新尝试后页面跟踪新任务编号；完成任务可通过复制任务重新创建。
