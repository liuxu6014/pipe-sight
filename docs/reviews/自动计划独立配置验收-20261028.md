# 简报自动计划独立配置

## 操作入口

- 情报简报列表、新建简报页均提供“新建自动计划”。不需要先生成简报或勾选候选文章。
- 情报简报的“自动任务”页提供“编辑计划”，可修改完整配置；仅本人可读取和修改计划。
- 可设置计划名称、每天/每周/每月、北京时间、每周具体星期、每月具体日期、对应模板、文章来源、后台类别、关键词和生成要求。
- 默认停用保存；明确开启“保存后启用计划”后才计算下次执行时间。保存本身不立即生成，也不创建生成任务。

## 筛选和执行规则

- 关键词默认空，支持自行输入；多个词任意命中。类别来自管理员配置。
- 来源、类别、关键词和报告周期共同限制候选文章；没有匹配文章则跳过生成。
- 日报取前一天，周报取执行日前七天，月报取上一个自然月。每月日期超过当月天数时在月末执行。
- 保存、编辑、启停、立即补跑是不同动作；编辑失败保留填写内容，不静默丢失筛选条件。
- 本次未启动任务工作进程。启用计划不代表已有工作进程实际运行；自动到点执行还依赖部署环境的任务进程。
