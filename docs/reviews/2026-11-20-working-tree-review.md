# PipeSight 当前工作区审查

审查基线为 `5b21f60` 及开始时已有的 83 个修改或未跟踪条目。旧审查按提交基线记录问题，本报告按当前工作区判断。审查从公开入口追踪到认证缓存、资料和报告存储、后台任务、采集调度及 PostgreSQL 部署配置。以下按修复优先级排列。

## P1

### 1. 并发请求可恢复已退出的会话

[认证续期](../../backend/src/app/system/services/authentication.py#L215) 先读取并比较 Redis 中的令牌，再用单独的 `SET` 写回旧值。请求读完后，如果退出先删除会话，续期请求仍会把旧令牌写回。单设备模式下，新登录先写入令牌时，同一个续期请求还会覆盖新会话。这也发生在退出接口已改用原子比较删除之后。隔离测试用真实认证和退出服务、内存 Redis，在读取与续期之间插入退出或新登录，两种情况均观察到旧令牌写回。改为原子比较并续期，条件失效时拒绝继续认证，覆盖多设备与单设备两种路径。

### 2. 上传私有资料会触发正文发送给配置的模型端点

[上传](../../backend/src/app/library/services/materials.py#L394) 为新资料自动排队，[分类 Worker](../../backend/src/app/library/tasks/material_parse_scheduler.py#L80) 把编辑或解析得到的正文交给分类服务，[模型网关](../../backend/src/app/research/services/model_generation.py#L125) 将正文发往所配置端点。现有类别的“全部”范围同时纳入上传资料，因此启用了类别和内容处理模型的实例，升级后可自动把新上传的私有资料交给外部供应商。资料库的“仅自己可见”保护站内访问，上传页没有提供是否交给该供应商的选择。实际模型调用取决于配置、扫描和解析结果。现有离线测试断言了分类请求包含完整测试正文，审查未发送真实资料。建议为私有资料使用独立、明确启用的数据处理策略，并在上传前显示处理目的和端点范围。

## P2

### 3. 上传失败会留下无数据库记录的文件

[上传入口](../../backend/src/app/library/api/controller.py#L65) 先持久化文件，[资料服务](../../backend/src/app/library/services/materials.py#L367) 随后检查共享范围和资料格式。后续拒绝时，没有补偿清理。用临时目录和合成 TXT 调用真实上传入口，确认不支持的共享范围被拒绝后，原始字节仍留在磁盘。后续数据库写入失败也缺少清理路径。应尽早校验业务参数，给落盘到数据库提交这一段增加清理与补偿，避免长期占用卷及备份空间。

### 4. 编辑资料会提前释放模型并发名额

[分类认领](../../backend/src/app/library/repositories/classification_repository.py#L42) 按状态为 `running` 的资料计数。[保存编辑](../../backend/src/app/library/services/materials.py#L443) 会把该状态立刻改为 `queued` 并清空令牌，已经开始的模型请求仍可继续执行。隔离测试中，两项已认领时第三项无法认领，编辑其中一项后，在旧任务尚未结束的情况下第三项可立即认领。旧结果不能覆盖正文，这一保护有效。应把已发起的请求名额保留至结束或超时，并独立标记资料需要按新版本重跑。

### 5. 删除报告后，导出和配图文件仍留在存储卷

[删除报告](../../backend/src/app/research/services/reports.py#L79) 删除数据库中的资源行和报告，[导出服务](../../backend/src/app/research/services/exports.py#L147) 将 PDF、Word 和配图持久化到文件卷。删除路径没有回收资源存储键对应的文件。用户从页面失去文件入口后，文件仍占空间并可进入后续卷备份。应记录待清理键，并在提交后可靠清理，保留失败重试能力。此项为源码调用链确认。

### 6. Worker 心跳正常时，业务队列可以持续停摆

[恢复循环](../../backend/src/app/research/tasks/research_job_scheduler.py#L195) 把科研恢复、导出、自动简报及资料处理放在同一个异常边界。前面的步骤持续报错时，后面的队列每轮都被跳过。[Worker 心跳](../../backend/src/app/health/worker.py#L30) 自行定时写入，仍可能报告健康。应单独捕获和记录各队列的扫描结果，同时观测最近成功时间、积压及最老任务等待时间。此项为源码调用链确认。

### 7. 生产 Compose 默认发布明文 API 端口

[生产 Compose](../../docker-compose.pg.yml#L73) 关闭应用传输加密，并将 API 的宿主机端口发布到所有接口。外部可达性取决于防火墙和宿主网络。若部署只对 Nginx 或上游配置了 HTTPS，直连已发布的 API 仍有独立的明文路径，也会绕过代理配置。前端容器与 API 已共享 Docker 网络，默认可移除 API 端口发布或绑定回环地址，再通过明确的 TLS 入口提供服务。此项为配置审查，未测公网可达性。
