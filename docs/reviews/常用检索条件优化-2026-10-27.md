# 常用检索条件优化

## 实现范围

新闻资讯、论文、资料库和全局关键词搜索接入统一的 `SavedSearchBar`。条目显示实际生效的筛选，可逐项移除；展开常用条件面板后可命名保存、应用或确认移除。未提交的搜索框草稿不冒充已执行的条件。

- 只保存白名单内的关键词、来源、类别/标签、年份/期刊、解析状态等控件值；不保存正文、文件、结果列表、密钥、游标或当前页码。
- 应用条件重置到第一页，保留每页条数和新闻列表/卡片视图；重新调用既有列表筛选链路，不在当前页结果上做假筛选。
- 原有清除筛选不删除已保存条件；移除常用条件也不删除任何文章、资料或报告。
- 每个账号、每类页面最多 12 组。相同条件重复保存更新名称；超限明确提示，不截掉旧条件。
- 语义搜索仍保持未接入状态，不伪装成关键词搜索，不保存为可执行条件。
- 调整新闻搜索框的旧「科技资讯」无障碍名称，并修正新闻/论文搜索框清空按钮被压成竖排的问题。

## 存储与隐私边界

使用当前浏览器的 localStorage，按十进制账号 ID 和页面类型分区。仅用户主动保存时写入，不自动记录搜索历史，不新增数据库表，也不做跨设备同步。

这是浏览器端的逻辑隔离，不是存储加密或服务端权限边界。面板明确提示共享电脑不要保存敏感关键词。账号切换立即清空上一账号的可见条目；异步删除确认在切换账号或卸载后不能继续写入旧账号记录。

存储权限不足、空间不足或记录损坏时明确报错，不提示保存成功，不覆盖损坏的原记录。不读取旧的非本功能存储键。
