# 文稿交付规范

适用范围：后续新生成的科研报告、日报、周报和月报。既有报告及历史引用不批量改写。

## 文章结构

文稿以明确的主题标题开篇，按用户确认的模板章节组织，开篇直接交代研究问题或主要判断。正文使用完整自然段，说明事实、依据、分析和结论之间的关系，不按资料编号逐篇拼接摘要。

科研报告围绕业务问题、已有进展、研究目标、实施路径及预期成果展开；未发生的研究活动使用“拟开展”等措辞。预算、指标和工程成绩必须有来源或测算依据，不以通用制度和占位字段填满章节。

情报简报按选定模板归纳事件与业务影响。日报关注事件和直接影响，周报归纳相关进展，月报梳理阶段变化；证据不能支持趋势时不作长期趋势判断。关闭热点分析时不额外添加热点或研判章节。

筛选类别不再自动变成新栏目。正文保留模板章节名称和说明，参考资料单独由系统整理。

## 正文边界

关键词、类别、来源范围、模板名称、目标条数、任务进度和生成设置均属于内部参数，不逐行回显在正文中。不出现“资料不足三条，所以不生成第三条”“为避免凑数”“按要求呈现”等执行说明。

资料少时允许短文，不允许重复扩写、虚构事件或量化结果。真实资料的不确定性和影响结论的限制必须保留；排版优化不能删除事实限定、冒充已阅读全文或把虚构样本改写成真实新闻。

## 引用和版式

- 引用只放在支持事实的句末、句号之前，同一句同一来源不重复，页面和导出使用上标。
- 参考资料按实际选材顺序连续编号，由真实标题、来源、日期和链接生成；模型生成的来源清单不得覆盖真实元数据。
- 只保留一份参考资料，不在正文附来源类型和日期的括号说明。
- 正文首行缩进两个字符，标题、参考资料不应用正文缩进；不靠空格和 HTML 伪造排版。
- Word 与 PDF 使用同一份规范正文和 A4 页面，保持清晰标题层级、可读中文字体、稳定段间距和页码。

## 验收边界

事实只限于输入资料明确支持的内容。有依据的保留句末引用并限定主体、时间和条件；二次导读只能说明导读所涉主题，不能替代论文全文结论。证据不足的判断改成可验证的问题，说明核实对象与方法，不能仅加“可能”后继续当作事实。未检索到资料不等于行业没有方法，也不能借相邻事实的引用为无据判断背书。

研究目标和方案须与这一边界一致：先调查是否存在困难，确认后再提出方法与条件性成果。不预设人工负担、方法稀缺、已获授权或性能优势。相同规则进入科研报告、日周月简报和局部改写的实际模型提示；规则不是独立的自动事实认证，仍须审读输出。

新生成文稿写入成果前执行结构与引用编号检查：拒绝空正文、空章节、代码围栏、残留 HTML、无法对应选材的来源标记以及超出范围的引用序号。已有选材但正文完全无引用时，任务明确失败，不通过附加来源清单冒充已有论据；原始模型结果保留在任务中，原报告不被覆盖，也不自动重试计费。

这项检查不要求所有资料都必须被引用，也不要求建议句逐句挂引用。它不判断引用是否真正支持对应事实，不能标记为事实核验通过。人工编辑允许保存草稿，不因稿件尚未完成而阻断保存。

生成后的任务展示、自动写入和手动应用使用同一正文规范。原始供应商结果仅保留用于追溯，不直接作为完成态正文展示。手动应用旧任务不强制补造引用，但仍拒绝无效编号和空结构。

中英文参考资料标题使用相同识别规则，保存不因“参考文献”或“References”额外追加第二份来源清单。新文稿的模型来源清单按各级标题识别并替换为真实选材元数据；已有作者及来源名称应保留，未知时不编造。

Word 导出保留正文粗体、斜体和上标引用，不把编辑器的强调标记直接删除为普通文字。样稿仍须逐页检查，结构化测试不能代替渲染验收。

测试通过或任务完成只证明链路执行成功，不能代替内容审读。交付前应检查章节逻辑、重复内容、事实支撑、引用对应和实际渲染；重要技术结论仍需业务人员复核。不得把配置检查或引用格式化说成已完成事实核验。
