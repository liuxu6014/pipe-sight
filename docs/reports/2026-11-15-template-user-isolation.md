# 模板用户隔离与网页流程验收

2026-11-15，在本地 PostgreSQL/Redis 环境、已登录的普通账号下验收。基于 `0304a17` 的 `templates.user_id` 隔离实现补齐普通用户操作闭环；未修改管理员模型权限或历史模板归属。

## 发现与修复

- 普通账号的模板列表正确为空，但没有个人模板管理入口，报告与简报新建流程无法继续。新增账户菜单“我的模板”，并在报告、简报及自动任务表单内提供管理弹窗，保留正在填写的内容。
- 内置模板安装脚本按全局名称去重，第二个账号无法安装同名模板。改为按所有者去重，并新增登录用户主动添加内置模板的接口；仅复制版本化内置内容，不读取其他账号的私有配置。包含三个报告类型各三份模板，以及日报、周报、月报各一份。重复添加保留个人修改和启停状态。
- 模板管理补齐章节提示词编辑，默认内容可带入本次生成的大纲；简报分类下新建模板使用简报用途，科研类型选项不混入简报。
- 报告局部改写的模板查询补上所有者条件；原有报告仍按报告所有者读取，不加载他人的模板。
- 更新迁移验收脚本的当前 Alembic head，以及新增模板归属字段后的注释数量断言。校正模板接口权限和私有资料测试的旧前提，保留真实权限断言。

## 网页实际操作

1. 普通账号初始无法看到管理员的 15 份模板；主动添加内置模板后得到自己的 12 份副本，再新建一份验收模板。重复添加仍为 13 份，不覆盖修改。
2. 验收模板创建、修改、停用、重新启用成功；两章写作要求保存后，在新建报告最后一步与正文提示词一起自动填充。
3. 报告流程：基本信息 → 公开新闻与论文各一条 → 个人模板 → 大纲确认 → DeepSeek 实际生成。任务 `194` 完成，报告 `193` 可阅读，引用来源可打开辅助面板；编辑标题保存后重新打开仍保留。
4. 从网页下载 Word/PDF 成品；DOCX 可读取并包含预期章节与参考资料，PDF 共两页，标题与章节文本完整。文件位于本机下载目录，未提交仓库。
5. 周报流程：选择 2025-04-07 至 2025-04-13 的公开新闻，使用个人周报模板；任务 `199` 完成，简报 `198` 显示分类、事件、摘要、洞察和真实数据源。
6. 自动任务按周/月切换时只显示当前账号对应周期模板；内嵌管理弹窗重复添加后关闭，计划名称、周期及模板选择仍保留。保存一份明确停用的月报验收计划，不启用周期执行。
7. 只读数据库检查确认新报告、简报、验收计划引用的模板均属于同一用户。与启动前 `before-start.dump` 对比，管理员原有 15 份模板的全部原字段内容一致。

以上网页操作使用一个真实普通账号；跨账号拒绝行为通过两主体 HTTP/真实仓储的 SQLite 与隔离 PostgreSQL 测试验证，并未冒充第二个网页登录会话。此次没有等待下一次自动计划触发；自动执行与跨用户模板拒绝由后端测试覆盖。
