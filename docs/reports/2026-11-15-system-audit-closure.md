## 修复范围

| 项目 | 最终行为与验证 |
| --- | --- |
| F01 私有文件下载 | 通用资源下载只允许公开头像命名空间，并拒绝指向私有目录的符号链接。私有资料继续通过归属与扫描检查的专用下载；增加跨入口回归。 |

| F03 生成契约 | 三类科研报告统一核对已确认章节的名称、集合、顺序及最低正文完整性。明显缺章/错序/超短拒绝；一般篇幅偏差形成版本化提示。只允许剥离一个没有正文的总标题，且剩余章节须与确认大纲逐项一致。 |
| F04 引用检查 | 按实际勾选执行，记录引用编号、来源、每处正文原句和位置。检查结果绑定文稿版本；编辑过程中及保存后旧结果失效。明确不代表事实核验。 |
| F05 模板周期 | 新增显式 `digest_cadence`，模板改名不再改变周期资格；历史日报保留读取，当前新建流程仅提供周报、月报。 |
| F06 数据源 | 管理员可配置受支持的网站、论文、公众号来源；校验适配器、HTTPS 入口、数量与频率，编辑保留配置。新增来源默认停用，可由管理员手动试采，不会因此开启定时采集。入队后被停用的旧任务仍取消。 |
| F07 自动任务 | 启用的自动任务阻止关联模板被停用/删除，并指出具体任务。永久配置错误挂起任务；临时错误按有上限的指数退避重试，不推进业务周期。 |
| F08 并发与恢复 | PostgreSQL 原子领取限制全局、用户、模型在途任务；按用户公平分发并排除已满的用户/模型，查询批次和导出并发有上限。Worker 退出时即使只有资料解析任务也等待取消清理。 |
| F09 数据库分页 | 报告、资料、模板、任务列表按数据库计数、筛选、排序和分页，仅返回列表需要的摘要字段；正文、完整提示词及任务结果按详情读取。前端忽略旧请求、账号切换和卸载后的响应。 |
| F10 翻译合并 | 按论文、字段和原文版本合并首次并发请求；PostgreSQL 跨进程锁使用独立连接，避免业务池只有一个连接时死锁。等待者复用已落库译文，失败、取消、原文变化均保留重试/冲突边界。 |
