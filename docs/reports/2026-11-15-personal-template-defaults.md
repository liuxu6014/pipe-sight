# 个人默认模板与删除恢复验收

每个账号首次访问模板列表或报告/简报模板选择器时，自动获得独立的 11 份默认模板：三种科研报告类型各 3 份，周报和月报各 1 份。页面移除手动安装入口，仍可新建和编辑个人模板。

默认模板使用账号内唯一的稳定标识。已有同名模板只补标识，保留正文、章节、启停状态及修改时间。改名或删除后再次加载不会补回同一模板。历史日报模板继续保留在数据库中，不参与新任务选择。

删除采用可恢复删除，已生成报告及任务快照保留。普通列表和生成选择器不显示已删除模板；状态筛选选择“已删除”可预览或恢复。恢复后保持停用，需用户主动启用。编辑、删除、恢复和生成接口均按当前登录账号限制访问。

## 验证结果

- 前端全量测试 662 项通过，生产构建通过。
- 后端完整隔离 PostgreSQL 演练及测试 1,857 项通过，无跳过；Ruff 与差异格式检查通过。
- SQLite / PostgreSQL 实际 HTTP 与仓储测试覆盖两个普通账号首次访问自动初始化、重复访问、改名、删除、恢复以及跨账号写入拒绝。
- 真实网页登录账号“模板隔离验收B”：页面无手动安装按钮；删除周报默认模板后刷新仍不出现，切换“已删除”可以恢复；恢复后停用，可再次启用。默认模板改名后刷新，原名不会重复添加；验收后已恢复原名和启用状态。
- 本地数据库迁移前已备份。`20261115_template_defaults` 只新增 `preset_key`、`deleted_at` 及账号内唯一约束；迁移后核对原有 41 条模板的全部旧字段和所有报告指纹均未改变。
