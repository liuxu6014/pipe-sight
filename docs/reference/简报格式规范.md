# 周报与月报成品格式

版式依据：同目录的《生物安全日报示例.docx》，SHA-256 为 `2140fb322dce7d3667e783c6d481eb397cb5b4462ae7a938744584b76dc4c3d1`。参考文件只控制版式，不作为事实资料、固定分类或模型指令。

周报和月报共用如下结构：

1. 居中红色刊名，仿宋小二（18 磅）、加粗。覆盖周期另起一行居中，三号（16 磅），同年显示为「2025年4月1日到4月30日」。下方为红色分隔线。
2. 按实际内容类别分组，类别标题用中文序号，16 磅加粗。
3. 类别下按事件展示，事件标题用阿拉伯数字编号，14 磅加粗；事实摘要用 12 磅仿宋、首行缩进两字。
4. 每条摘要后依次展示发布时间、行业洞察、数据源。时间为浅绿块，洞察为浅黄块，来源为浅蓝块。时间缺失时省略，不使用采集时间冒充发布时间。
5. 每条事件独立列出来源，编号从 `[1]` 开始，保留原题、发布方及真实链接。不再追加重复的全局参考资料，也不添加综合导语或虚构趋势。

Word 使用从原文件提取的页面、段落、字体、编号和颜色样式，保留 A4 纸张及原页边距。网页正文 16px、事件标题 18px、类别标题 20px，刊名 21–24px。PDF 使用相同内容层级、色块及导出字号，字体按运行环境的中文字体支持回退。Word 和 PDF 分页时让行业洞察与首条来源相邻。源文档中的图片是具体新闻的可选内容，不复制示例图片或虚构配图。

新建周报、月报任务冻结 `document_format: digest-reference-v1`。模型提交分类、事件标题、摘要、洞察和带类型的选材标识，来源标题、发布方、时间和链接由服务器按冻结选材填入。同一事件合并展示，每条的首个来源在全篇仅用一次。保存前核对条数、摘要上限和来源。原始模型输出保留在任务结果中，重新应用生成结果需通过既有版本检查。

历史任务和已有人工编辑稿不批量重写。新格式的阅读、编辑及再次保存必须保留事件标题、逐条来源和原编号，不能把来源编号挪到句末或自动追加第二份参考资料。
